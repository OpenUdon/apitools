# v31 — Monthly maintenance and search for reviewed providers

The owner requested current publisher sources for the 334 reviewed providers,
an externally cached, searchable SQLite catalog, and a monthly program with
an agent maintenance skill. The source inventory includes 181 older
machine-readable references. Dropbox, HubSpot, Kubernetes, Stripe, Google
Sheets and Slack each need specific source selection or revision handling.
The working catalog includes the local C04/C05 changes.

The owner selected compatible local adoption and a reviewable Git export.
Use publisher links wherever possible, enumerate stable service links and
qualify the reviewed operations. Prepare bounded advisory overlays from
official docs when a usable spec is unavailable. Defer specs above one
decimal GB and specs whose size cannot be determined before download. Use a
configurable directory path for retained artifacts. This machine's mount
choice is recorded in the [C06 host configuration note](../memory-bank/status-C06.md).

The owner selected reviewed-first automatic CLI search with public discovery
for non-core queries, and hosted embeddings through a configurable endpoint
for curated public metadata and explicit search queries. SQLite text search
must work offline. Schedule management belongs to the package and its agent
skill. The approved [milestones](../memory-bank/milestone.md#monthly-reviewed-catalog)
cover APItools; the downstream stage is outside this request.
