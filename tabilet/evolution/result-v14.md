# Result V14 - n8n De-Emphasis Before Release

M52 removes active n8n-specific catalog surfaces before release.

The n8n Public API provider row, TimeSaved workflow helper row, n8n
node-directory candidate evidence, artifact registration, and n8n gap-report
CLI/API are removed. Public docs and active memory-bank guidance now describe
catalog expansion as provider-source-first.

M49-M51 remain historical records only. Future provider work must start from
provider-owned or protocol-owned evidence and must not copy third-party
integration code, generated node metadata, credential behavior, descriptions,
icons, or runtime workflow behavior.
