# Prompt V2 - Split Core Catalog Milestones

Refine the provider catalog plan so the broad M2 scope becomes four explicit
milestones:

- candidate service inventory;
- durable catalog entries and spec references;
- security overlays and auth/security classification;
- catalog resolution and CLI reporting.

The first milestone should establish a candidate list before committing entries
as built-in catalog data. `../try-n8n/reducibility/specs` may seed the initial
candidate set, and `../n8n/packages/nodes-base/nodes` may inform later service
prioritization, but neither source should imply n8n runtime compatibility.
