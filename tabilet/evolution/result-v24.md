# Result V24 - Step-contract operation metadata

**State:** Approved planning direction, 2026-09-26. The requested behavior
has not been implemented or accepted.

[M77](../memory-bank/status-M77.md) is the next and only active APItools
milestone. Its six pending rows define an additive public metadata contract,
consumer summaries, evidence-backed effects, step-contract ranking, integration
with existing source metadata, and qualification/consumer handoff.

The material direction change is a reusable operation-candidate contract that
explains purpose, input/output fit, and effect evidence to consumers. Existing
inventories, selection APIs, and lifecycle scoring remain compatible. New
metadata preserves source identity and native selectors, auth alternatives,
prompt budgets, and uncertainty. An HTTP method alone cannot prove read safety;
missing or conflicting evidence stays unknown. Ranking is advisory and grants
no authority to bind credentials, select accounts, approve, or execute.

OpenUdon M87.4 consumes the compatible published APItools interface; Kinet W03
consumes OpenUdon's commands. Contract design in each repository can proceed
independently, with reconciliation before the integration is frozen. APItools
qualifies its API and fixtures without a reverse dependency on Kinet delivery.
Publication and consumer re-pinning are later actions under separate authority.

Only the roadmap, M77 status, and this evolution pair change during planning.
Existing candidates, completed history, current architecture facts, sibling
repositories, and the optional goal protocol remain intact. No goal suggestion
file is created for this single milestone. Implementation tests and milestone
acceptance remain pending under the [M77 specification](../memory-bank/milestone.md#m77---step-contract-operation-metadata).
