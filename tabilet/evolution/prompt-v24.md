# Prompt V24 - Step-contract operation metadata

Plan APItools' contribution to sibling S2a: consumer-readable operation
summaries, evidence-backed read/write/unknown effect classification, and
ranking by a step's purpose, inputs, and outputs for OpenUdon's `step candidates`.
Build on existing inventories, summaries, source metadata, and ranking while
preserving existing exported contracts. Keep the first version deterministic
and offline, expose uncertainty and compatibility gaps, and retain workflow
decisions, approval, and execution with their downstream owners.

Source direction: [Kinet's design, section 7](../../../kinet/docs/icot.md#7-proposed-changes-by-package).

Implementation, commits, publication, and sibling changes require separate
execution authority.
